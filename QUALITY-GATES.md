# Quality gates — v6.3.3

| Gate | Must demonstrate | Blocks when |
|---|---|---|
| G0 Definition | objective, audience, action, landing scope and material inventory | a choice would materially change the project and remains unknown |
| G1 Strategy & Content | compiled context, five-lens current reference evidence, structurally challenged flow, usable copy, truthful claims and primary/utility scene map | context, reference calibration, structural specificity or claim evidence is missing |
| G2 Creative Direction | project-specific premium bar, three physically distant territories, isolated selection, one generated master, confirmation and complete design genome | territories converge, selection is self-approved, source traceability fails or the master/genome is incomplete |
| G3 Visual Experience | scene grammar, direct/high-end comparison for every section, derived foundations, explicit colors, responsive evidence and coherent rhythm | any scene lacks relational grammar, value decision, color assignment, responsive behavior or master continuity |
| G4 Production | structural build, render-derived `IMAGE | NO_IMAGE` decisions, complete external handoffs, returned assets, integrated executable landing, runtime evidence and independent build review | a scene decision, required return, integration, effect/runtime fallback, responsive evidence or critical quality is missing |
| G5 Release | G0–G4 approved, physical delivery checks, no blocking findings and a reusable design fingerprint | state, evidence, implementation or recorded visual identity disagree |

Scripts decide whether observable evidence exists and is internally consistent. Agent 07 decides whether rendered design quality is sufficient.
