- eight roles, six gates, twelve stages and twelve project artifacts;
- adaptive `LOW | MATERIAL` perceptual opportunity;
- per-image truth and production decisions;
- independent direction, design and build reviews.

## IMPROVE

- observe whether agents create useful body-scene compositions instead of duplicating the hero language;
- refine decomposition checks from real failures without prescribing a frontend stack;

- element-by-element design without scene-level composition when material;
- flattened section screenshots, baked interface text and controls;
- accidental promotion of a `CMP-*` into an `IMG-* FINAL`.
