# Creative Resource Registry

Catálogo conservador para referencias, código creativo, assets y tooling. Sirve a 01/03/04/05/06 cuando existe una incertidumbre concreta; no es una lista de tendencias. Al explorar un efecto material, usa anclas funcionales para evitar inventarlo o descartarlo sin contraste.

Cada fuente declara fit, límites, stack, coste, licencia, reuse class y caducidad. La decisión por defecto sigue siendo `NO_EXTERNAL_RESOURCE_REQUIRED` cuando consultar recursos no cambia materialmente el resultado.
