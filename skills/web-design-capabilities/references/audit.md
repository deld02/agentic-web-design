# Interface audit capability

Run on the real build after functional journeys work. Universal web behavior is mandatory; source-brand preferences are advisory.

Audit:

- semantic structure, keyboard operation, focus visibility and management;
- controls, labels, forms, errors, autocomplete and hit targets;
- responsive overflow, mobile inputs, safe areas and content variability;
- motion preferences and interaction feedback;
- images, dimensions, loading, text rendering and content quality;
- performance risks relevant to the selected technology.

Tag findings `UNIVERSAL | STACK_SPECIFIC | SOURCE_BRAND_PREFERENCE`. Only the first two can block, and stack-specific rules apply only to the actual stack.

Write location, evidence, severity, owner, fix criterion and status in `qa-release.md`.
